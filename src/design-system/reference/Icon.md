# Icon

The system's 24-unit line icon set: 1.75 stroke, round caps and joins, drawn in `currentColor`.

**Consumer provides:** `name` (see `Icon.names`), optional `size` (`lg` = 20px; default 16px), `label` (only when the icon stands alone and means something; otherwise it's hidden from screen readers).

- Icons sit beside a text label; an icon-only button needs `aria-label`.
- Icons take the colour of their text. Never colour an icon on its own to carry status.
